# @codeatlas/contracts

TypeScript package for the canonical CodeAtlas contracts (FND-03). Everything in it is derived from [`contracts/schemas/codeatlas.schema.json`](../../contracts/schemas/codeatlas.schema.json); nothing is hand-written contract code except two small version helpers.

| Export | Source |
|---|---|
| One type per schema `$defs` entry (`Node`, `Edge`, `InitializeParams`, ...) | `src/generated/contracts.ts`, generated by `json-schema-to-typescript` |
| `CONTRACT_VERSION`, `PROTOCOL_VERSION`, `Method`, `ErrorCode` | `src/generated/constants.ts`, generated from the schema's `x-*` fields and enums |
| `protocolCompatibilityKey`, `isProtocolCompatible` | `src/index.ts` (same rule as the Rust engine) |
| `@codeatlas/contracts/schemas/codeatlas.schema.json` | copied from `contracts/schemas` at build time |

It is CommonJS with type declarations, so it works from CommonJS (the VS Code extension) and from ES modules or bundlers (the platform). It has no runtime dependencies. `private: true` prevents an accidental registry publish; registry releases come with DIST-01.

## Scripts

```sh
npm ci
npm run generate          # regenerate src/generated/* and test/examples.generated.ts
npm run check:generated   # CI: fail if generated files are stale
npm run format            # Prettier, 4-space indent (config: repo-root .prettierrc.json)
npm run format:check      # CI: fail if a file is not formatted
npm run typecheck         # sources + every valid schema example against its type
npm run test:consumer     # pack, install into a fresh project, type-check (ESM + CJS) and run
npm pack                  # the contract artifact consumers pin
```

Do not edit generated files by hand. Change the schema and follow [`contracts/README.md`](../../contracts/README.md) "Changing a contract".
